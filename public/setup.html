Connect Google Calendar

Your start page reads your calendar through its secret iCal address, so there’s no Google sign-in and it can’t change anything.

Where to find it
  1. Open Google Calendar on the web: calendar.google.com
  2. Click the gear icon, then Settings.
  3. Under Settings for my calendars, choose the calendar you want to show.
  4. Scroll to Integrate calendar and copy Secret address in iCal format.
    It ends in /basic.ics. Not the Public URL, the embed code or the link in your address bar.

Connect GitHub

A personal access token lets your start page read your notifications, pull requests and activity. Keep it private: classic tokens can’t be limited to read-only.

Where to find it
  1. Go to github.com/settings/tokens and open Tokens (classic).
    Fine-grained tokens can’t read notifications, so this needs a classic token.
  2. Click Generate new token (classic). Name it start-page and set an expiration.
  3. Tick only these scopes:
    notifications  your inboxrequired
    read:user  your profile and contributionsrequired
    repo  only if you want private repositoriesoptional
  4. Click Generate token and copy it right away.
    GitHub shows the token only once.
